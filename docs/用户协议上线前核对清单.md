# 靓丝用户协议上线前核对清单

本清单不属于《靓丝用户服务协议》正文，仅供产品、运营和法务上线前核对。

## 必须补全

- [ ] 运营主体法定全称
- [ ] 统一社会信用代码
- [ ] 注册地址和实际联系地址
- [ ] 客服电话、客服邮箱及应用内客服/投诉入口
- [ ] 协议发布日期和生效日期
- [ ] 《靓丝隐私政策》的可访问链接
- [ ] 账号注销的应用内路径；如尚无自助注销功能，至少提供有效、便捷的人工申请渠道
- [ ] 用户对账号限制、评价删除等处置措施的申诉入口和处理流程
- [ ] 商家主体信息展示、资质核验、投诉转交和纠纷协助流程

## 与当前产品保持一致

- [ ] 确认产品确实不提供在线充值、支付、代收款、退款或消费信贷
- [ ] 核实取消规则：待商家确认可取消；确认后距开始超过三小时可取消；不足三小时联系商家
- [ ] 核实“累计三次爽约可能限制预约”的口径、统计周期、限制期限和申诉机制
- [ ] 核实价格展示究竟是固定价、参考价还是起步价，并在服务页明确标注
- [ ] 明确预约在“用户提交申请”还是“商家确认接单”时成立，产品文案和协议应一致
- [ ] 核实评价是否公开展示；若仅用于投诉处理，应删除协议中公开展示评价的相关描述
- [ ] 确认第三方服务清单（目前代码可见高德定位、短信、相册/相机等），并在隐私政策中逐项披露
- [ ] 登录页品牌文案目前仍出现“Hot Pepper Beauty”，上线前应统一为“靓丝”

## 展示与留痕

- [ ] 注册/首次使用前提供未预先勾选的同意选项，并允许完整阅读、保存协议
- [ ] 对平台性质、线下结算、责任限制、账号处置和争议解决等重大利害条款显著展示并可按用户要求说明
- [ ] 在应用首页或便于查找的位置持续公示现行协议及历史版本，支持完整阅览和下载
- [ ] 修改平台规则时依法公开征求意见、留档，并至少提前七日公示；重大修改至少提前十五日公示
- [ ] 不把增加用户义务或减损用户权益的修改设置为默认同意
- [ ] 保存用户同意的协议版本、时间和必要日志，以便证明已履行提示及说明义务

## 法务提示

- [ ] 由熟悉中国互联网平台、消费者权益和个人信息保护的律师结合实际业务复核
- [ ] 若未来增加线上支付、会员充值、优惠券、直播、AI试发型、社区互动或跨境业务，应在功能上线前重新修订协议和隐私政策
